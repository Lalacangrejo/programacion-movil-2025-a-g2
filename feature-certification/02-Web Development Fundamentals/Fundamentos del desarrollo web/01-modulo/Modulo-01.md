# 💻 Resumen General – Fundamentos de Computación y Desarrollo Web

Este curso te brinda los conocimientos esenciales para comprender cómo opera una computadora y cómo se crean páginas y aplicaciones web. Inicia desde lo básico hasta llegar a la creación de sitios seguros y bien diseñados.

---

## 🔹 Módulo 1: Funcionamiento de una computadora

Una computadora sigue 4 etapas clave:  
➡ **Entrada** (como teclado o sensores)  
⚙ **Procesamiento** (la CPU transforma los datos)  
📤 **Salida** (pantalla, impresora, etc.)  
💾 **Almacenamiento** (RAM o disco duro)

También conociste:

- **Hardware**: componentes físicos  
- **Software**: programas que hacen funcionar la compu  
- El **sistema operativo** gestiona todo el sistema  
- La **Internet** y los **navegadores** permiten navegar por páginas web  

---

## 🔹 Módulo 2: Introducción a la programación

Programar es comunicarse con la computadora usando instrucciones, que al final se traducen a lenguaje binario (ceros y unos).

**Tipos de lenguajes:**

🧠 **Compilados** (como C++): rápidos y eficientes  
💬 **Interpretados** (como Python o JavaScript): fáciles de escribir y entender  
El código se transforma mediante **compiladores** o **intérpretes**.

---

## 🔹 Módulo 3: Fundamentos del desarrollo web

Crear para la web implica construir sitios y aplicaciones en línea. Esto involucra:

👨‍💻 El **desarrollador web**: define estructura y funcionalidad  
🎨 El **diseñador web**: cuida la apariencia y experiencia de usuario (UX/UI)  

Los sitios incluyen texto, imágenes, formularios, enlaces, etc.  
Pueden ejecutarse en el **cliente** (navegador) o en el **servidor** (back-end).

---

## 🔹 Módulo 4: Front-end y diseño responsivo

El **front-end** es la parte visual con la que interactúan los usuarios.

**Lenguajes esenciales:**

🧱 **HTML** – estructura del sitio  
🎨 **CSS** – diseño y estilo  
⚡ **JavaScript** – comportamiento e interacciones  

El diseño **responsivo** permite que los sitios se adapten a diferentes dispositivos mediante **media queries**.

---

## 🔹 Módulo 5: Back-end y bases de datos

El **back-end** gestiona todo lo que no ves directamente en la web:

🔐 Manejo de usuarios y autenticación  
🧠 Lógica del sistema  
📊 Almacenamiento y gestión de datos  

**Lenguajes comunes:** PHP, Python, Node.js  
Las **bases de datos** como **MySQL** almacenan la información utilizando **consultas SQL**.

---

## 🔹 Módulo 6: Seguridad y buenas prácticas

Para asegurar un sitio web es fundamental:

✅ Validar correctamente los formularios  
🔒 Cifrar la información sensible  
👤 Autenticar usuarios  
🚫 Restringir accesos no autorizados
