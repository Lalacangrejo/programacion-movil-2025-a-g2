Resumen de los Módulos de Desarrollo Web
✅ Módulo 1: Navegadores web y lenguaje de marcado
🌐 ¿Cuál es la función de los navegadores web?
Permiten visualizar y manejar información en línea. Interpretan código HTML para mostrar las páginas correctamente.

⚙️ ¿Qué significa "marcado"?
Es el uso de HTML, un lenguaje que indica cómo debe visualizarse el contenido. Funciona como una guía para que todos los navegadores muestren la página de forma coherente.

❗Problemas comunes solucionados:

Incrustaciones excesivas: muchos recursos (imágenes, scripts) pueden disminuir la velocidad de carga.

Tamaño del archivo: documentos pesados afectan el rendimiento.

Compatibilidad: antes cada navegador interpretaba diferente; hoy existen estándares que unifican.

✅ Módulo 2: HTML – Estructurando la web
🏗️ ¿Qué es HTML?
Es un lenguaje declarativo que define la estructura del contenido. Indica qué elementos deben mostrarse, no cómo deben lucir.

📚 Componentes de HTML:

Etiquetas: como <p>, <h1>, <img>, etc.

Atributos: detalles adicionales, como src, href, alt.

Esqueleto del documento: establece el orden y la jerarquía.

✍️ Ejemplo simple:

html

Editar
<!DOCTYPE html>
<html>
  <head><title>Título</title></head>
  <body>
    <h1>Encabezado</h1>
    <p>Texto de ejemplo</p>
  </body>
</html>
✅ Módulo 3: HTML5 – Avances en el marcado
🚀 ¿Qué aporta HTML5?

Etiquetas semánticas nuevas: <header>, <nav>, <footer>, entre otras.

Soporte incorporado para video, audio y formularios más modernos.

Mayor compatibilidad con JavaScript y CSS.

🔁 Estándares de compatibilidad:
Para que los navegadores interpreten HTML5 correctamente, deben ajustarse a normas comunes.

✅ Módulo 4: CSS – Estilizando la web
🎨 ¿Qué es CSS?
Es el lenguaje que permite personalizar la apariencia de las páginas: colores, tamaños, ubicaciones, etc.

📜 Formas de aplicar estilos:

En línea: dentro de la etiqueta (<p style="color:red;">)

Interno: en la sección <style>

Externo: en archivos .css, ideal para mantener orden.

📐 Sintaxis básica:

  propiedad: valor;
}

🎯 Tipos de selectores:

.clase → aplica estilo a varios elementos

#id → estilo exclusivo para un solo elemento

✅ Módulo 5: JavaScript – Interactividad en acción
⚡ ¿Qué es JavaScript?
Lenguaje que agrega dinamismo a las páginas web: respuesta a eventos, validaciones, animaciones, entre otros.

🔧 ¿Qué funciones cumple?

Modifica el contenido sin recargar la página

Verifica datos en formularios

Reacciona ante acciones del usuario

🧠 ¿Dónde se utiliza?

Dentro de etiquetas <script>

En archivos externos con extensión .js
